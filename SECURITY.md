# Security

agentfence reduces the blast radius of mistakes made by a coding agent. It is not a sandbox and it is not designed
to stop a determined attacker (see "Limits" in the README).

If you find a way to run a command that a built-in rule is meant to stop, please open an issue with the command.
If you think the issue is sensitive (for example, it affects how agentfence parses its own policy files),
use GitHub's private vulnerability reporting on this repository instead.
